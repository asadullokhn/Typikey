Edit Page edits again.

It had stopped opening the button editor. Tapping "Edit Page" still let you rename the page, so it looked like it was working — but tapping a key on the board did nothing at all, and there was no way to change what any key says.

Tapping a key while editing now opens the editor, and the key stays ringed while it is open. Blank cells appear while editing too, so a new page is something you can actually put keys on rather than an empty board with nothing to touch.

Being in edit mode is now visible before you tap anything: the Edit Page button fills in, and the tray behind the keys turns blue, the same way it changes colour for private mode. The keys themselves never change — same words, same colours, same places.

Two smaller things: a key set to open another page now opens it here as it already did on the keyboard, instead of typing its own name. And empty cells now announce themselves to VoiceOver rather than being silent.

Please try: Edit Page, then tap any key and change its label. Then Add New Page and put a few keys on it. Check the blue tray makes it obvious which mode you are in.
